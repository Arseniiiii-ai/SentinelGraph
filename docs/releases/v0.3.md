# SentinelGraph v0.3 — Behavioural ML and Anomaly Detection

## Release outcome

v0.3 introduces a strict point-in-time behavioural feature store and evaluates
supervised, unsupervised, and anomaly-augmented challengers. It stops before
transaction-graph intelligence, calibration, explanations, APIs, and MLOps.

## Delivered

- 23 leakage-safe account and counterparty behavioural features.
- Strict prior-step windows that exclude ambiguous same-hour activity.
- 24-hour, 168-hour, and lifetime velocity aggregates.
- Amount-deviation and historical transaction-type features.
- Counterparty-diversity and cold-start indicators.
- Isolation Forest trained only on legitimate development behaviour.
- Behavioural histogram gradient boosting.
- Anomaly-augmented gradient boosting with a validation-only complexity hurdle.
- Future-time, new-account, and sliced evaluation.
- Reproducible feature and model manifests.

## Key future-time results

| Model | PR-AUC | Recall | FP / 10k legitimate | Captured fraud amount |
| --- | ---: | ---: | ---: | ---: |
| v0.2 gradient baseline | 0.40481 | 47.45% | 56.08 | 80.11% |
| Isolation Forest | 0.04205 | 33.06% | 635.95 | 74.70% |
| Behavioural gradient boosting | 0.60967 | 69.04% | 79.01 | 92.61% |
| Behavioural + anomaly boosting | 0.60539 | 71.09% | 104.50 | 92.91% |

The selected v0.3 model is behavioural gradient boosting. The anomaly feature
added only 0.00013 validation PR-AUC, below the documented 0.005 complexity
hurdle, and is retained as a documented negative result rather than promoted.

## Reproduce

```bash
uv sync --extra dev
uv run sentinelgraph-data all
uv run sentinelgraph-baselines
uv run sentinelgraph-behaviour
```

Tracked results are stored in `reports/v0.3/behavioural_metrics.json`. Generated
feature Parquet and model binaries remain ignored under `data/processed/` and
`models/v0.3/`.
