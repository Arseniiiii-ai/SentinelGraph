# SentinelGraph v0.5 — Calibrated Risk Engine and Explanations

## Release outcome

v0.5 converts the behavioural champion, anomaly detector, and graph challenger
into a temporally governed risk product. It delivers calibrated probabilities,
0–1000 risk points, three-way policy simulation, reason codes, local
explanations, and operational value backtests. It stops before API serving,
PostgreSQL, authentication, and investigator workflow.

## Delivered

- Separate development, calibration-fit, calibration-selection,
  policy-selection, and untouched future windows.
- Sigmoid, isotonic, and logistic score-stack calibration candidates.
- Calibration selection using Brier score with a ranking-retention guardrail.
- Classifier, anomaly, and graph evidence combination.
- `approve`, `review`, and simulation-only `decline` decisions.
- Review-capacity, decline-capacity, and decline-precision constraints.
- Brier score, log loss, ECE, reliability bins, and future evaluation.
- Queue-size, fraud-capture, and transparent cost-proxy backtests.
- 0–1000 risk points and de-identified reason-code examples.
- End-to-end local legitimate-median occlusion as a bounded SHAP alternative.
- Policy, calibration, explanation, and artifact regression tests.

## Key results

| Measurement | Future-time result |
| --- | ---: |
| Selected calibrator | `logistic_score_stack` |
| PR-AUC | 0.61382 |
| Brier score | 0.00547 |
| Expected calibration error | 0.00653 |
| Review queue rate | 0.979% |
| Simulated decline rate | 0.134% |
| Flagged fraud recall | 61.47% |
| Recovered fraud amount proxy | 83.93% |

The raw balanced classifier substantially overstates probability: its mean
selection-window score is 10.74% against a 1.34% fraud rate. The selected score
stack reduces selection Brier score from 0.04440 to 0.00675 while improving
PR-AUC from 0.68602 to 0.69193.

## Guardrails

- Future steps 521–743 are not used for model, calibration, or policy fitting.
- `Decline` is an offline recommendation and triggers no customer action.
- Cost assumptions are scenario inputs on synthetic PaySim, not forecasts.
- Local explanations describe model sensitivity, not causality.
- Raw account identifiers never enter model matrices or explanation artifacts.
- Joblib checksums remain in an ignored local manifest because byte-level
  serialization is not treated as canonical semantic evidence.

## Reproduce

```bash
uv sync --extra dev
uv run sentinelgraph-data all
uv run sentinelgraph-behaviour
uv run sentinelgraph-graph
uv run sentinelgraph-risk
uv run pytest -q
```

Tracked metrics are stored in `reports/v0.5/risk_metrics.json`; tracked
explanation samples are stored in `reports/v0.5/reason_code_examples.json`.
