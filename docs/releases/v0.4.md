# SentinelGraph v0.4 — Transaction-Graph Intelligence

## Release outcome

v0.4 builds an exact point-in-time account graph, evaluates graph-only and
behavioural-plus-graph challengers, and makes an evidence-based keep/remove
decision. It stops before calibration, explanations, APIs, and MLOps.

## Delivered

- Directed PaySim account graph with reproducible topology statistics.
- Strict prior-step node degree, direction, flow, and role features.
- Exact incremental weak-component features.
- Same-step edge exclusion.
- Explicit prohibition of label-based neighbour exposure without a
  fraud-confirmation timestamp.
- Graph-only and behavioural-plus-graph histogram boosting experiments.
- Temporal validation, future-time, and new-account evaluation.
- Automated graph leakage and artifact tests.
- Graph feature dictionary, metrics, and technical report.

## Key future-time results

| Model | PR-AUC | Recall | FP / 10k legitimate | Captured fraud amount |
| --- | ---: | ---: | ---: | ---: |
| v0.3 behavioural champion | 0.60967 | 69.04% | 79.01 | 92.61% |
| Graph-only boosting | 0.61776 | 67.23% | 68.73 | 91.85% |
| Behavioural + graph boosting | 0.60478 | 68.38% | 78.51 | 92.46% |

The graph-only challenger improved future PR-AUC and reduced false positives,
but its validation PR-AUC gain was only 0.00120, below the documented 0.005
materiality hurdle. Graph augmentation reduced both validation and future
PR-AUC. The v0.3 behavioural model therefore remains the release champion.

GraphSAGE is not retained: all directed pairs occur once, no reciprocal pairs
exist, the final weak graph is acyclic, and the non-GNN graph features do not
show material validation lift.

## Reproduce

```bash
uv sync --extra dev
uv run sentinelgraph-data all
uv run sentinelgraph-behaviour
uv run sentinelgraph-graph
```

Tracked metrics are stored in `reports/v0.4/graph_metrics.json`. Generated
graph Parquet, component arrays, and model binaries remain ignored.
